# Как работает СтройКонтур

В системе есть строительные объекты и задачи по каждому объекту. Руководитель создаёт объект, указывает адрес, затем добавляет задачи и назначает ответственных. В списке объектов видно количество работ и их состояние. Поиск и фильтр помогают найти нужное.

Исполнитель входит под своей учётной записью. Он видит только назначенные ему задачи и те объекты, где у него есть работа. Даже на общем объекте чужие задачи для него скрыты. Он может взять новую задачу в работу и передать готовый результат руководителю на проверку. Редактировать задание, назначать другого ответственного, удалять данные или самостоятельно принимать свою работу исполнитель не может.

Руководитель принимает результат либо возвращает его на доработку с обязательным пояснением. После исправлений исполнитель повторно отправляет работу на проверку. Перепрыгнуть через этапы нельзя. В карточке задачи автоматически записывается, кто и когда изменил статус, какой статус был раньше и какой стал, а также комментарий. Сотрудники не могут исправлять или подделывать эти записи.

Защита действует внутри базы данных — хранилища информации. Поэтому ограничения сохраняются, даже если кто-то попытается отправить запрос в обход сайта. Полномочия пользователя хранятся отдельно от данных, которые он может редактировать. Новые учётные записи создаёт администратор; свободную регистрацию необходимо отключить в настройках Supabase перед сдачей.

Демонстрационный режим предназначен для знакомства с интерфейсом: он хранит пример данных в браузере и не обеспечивает защиту реальных данных. Настоящий вход и описанная защита работают после подключения Supabase и применения миграции. В рабочей версии отсутствуют кнопки выбора демонстрационной роли.

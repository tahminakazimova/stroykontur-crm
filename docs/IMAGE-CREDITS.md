# Фотографии объектов

Фотографии — иллюстрации типов зданий, а не изображения реальных объектов из демобазы. Источники: бесплатные фотографии Unsplash. Изображения сохранены в public/images, чтобы карточки работали без внешних запросов к фотосервису.

- Жилой комплекс: Yansi Keim — https://unsplash.com/photos/_4U19TDp1bw → residential.jpg
- Бизнес-центр: Declan Sun — https://unsplash.com/photos/LdLxQxpU6k8 → office.jpg
- Загородный дом: Arthur BAUDRY — https://unsplash.com/photos/4vioYQ9Nn9Y → house.jpg

Карточки используют HTML img с object-fit: cover и поясняющим alt. Изображение выбирается по типу названия объекта: бизнес-центр/офис, дом/коттедж либо жилое здание. CSS-имитации зданий удалены.
